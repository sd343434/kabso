- **Licence of the SVG files:** CC0 1.0 Universal (Simple Icons, https://simpleicons.org, npm `simple-icons@15.9.0`).
  The files are copied byte for byte. The paths are not edited, redrawn or recoloured in the file.
- **The marks are trademarks of their owners** (Meta Platforms for Instagram, Facebook and WhatsApp; Snap Inc. for
  Snapchat). CC0 covers the drawing, not the trademark. They are used only as "follow us" links to Kabso's own pages,
  which each guideline allows. They are not used as Kabso's own marks.
- **How they are shown:** each mark whole and unaltered, in **one colour** (the theme's text colour, monochrome as
  every guideline allows), centred in a neutral circle, never rotated, stretched, outlined or combined with
  another mark (`FounderSocialRow`, CONVENTIONS §10.153).
