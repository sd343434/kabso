## Updating

1. Download the new version at a pinned commit.
2. Replace `confusables.txt`.
3. Run `node scripts/generate-confusables.mjs`.
4. Update this README and the pinned hash in the spec.
5. Run the tests.

The skeleton changes, so re-check the reserved-term test lists.
