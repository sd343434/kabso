# UI audit: current state before the design correction sprint (KL-030)

This folder records **what the app renders today**, before any redesign. It contains captures
only, with no proposals.

## How these were produced

- **Method:** a headless Flutter render of the real app. These are **not** screenshots from a
  device or emulator; none is available in this environment. The harness pumps the production
  widget tree:
  - `KabsoApp` (`MaterialApp.router`);
  - the production `GoRouter`, including the `StatefulShellRoute` 5-tab shell and the auth
    redirect;
  - the production theme and gen-l10n strings.
- **Data:** a fake `AuthRepository` at the repository boundary, from `test/helpers/fakes.dart`.
  - Signed-in user: "Layla" / `@layla.k`.
  - Settings shows two fake sessions.
  - The splash capture uses a session restore that never completes.
  - Nothing else is faked, so every screen shows its real production state. Today that is
    mostly the "coming in Phase N" empty states.
- **Navigation:** each capture launches through the splash (session restore) and then
  navigates with `GoRouter.go(<route>)`, as a user would.
- **Harness:** `apps/mobile/tool/ui_audit/capture_test.dart`. It lives outside `test/` and is
  **not** part of the normal `flutter test` run.
- **Command** (Linux, Flutter 3.47.7 / Dart 3.13.5):

  ```sh
  cd apps/mobile
  flutter test tool/ui_audit/
  ```

- **Commit:** the app code is at `b764a5c` (the integration branch HEAD at capture time). The
  harness and these images are added on top of it in the KL-030 commit, with no app code
  changes.
- **Viewport:** 393×852 logical px, devicePixelRatio 3.0, so each PNG is 1179×2556.
  - No system status bar or navigation bar is drawn, and the safe-area insets are 0.
  - On a real device the content would start below the status bar.
- **Fonts:** the bundled Inter and IBM Plex Sans Arabic, plus Material Icons, all loaded with
  `FontLoader` (not the Ahem test font).
- **Locales and themes:** every screen in `ar` (RTL) and `en`, in the dark theme (the default).
  The Home tab is also captured in the light theme.
- **Time:** the clock is fixed at 2026-10-16 09:00 UTC, so relative times are stable.
- **Animations:** animations are not disabled; this is the real app. Spinners and skeleton
  shimmer are caught mid-frame.
- **`component-*` files:** these are **copies** of the existing approved goldens from
  `apps/mobile/test/goldens/png/` (generated by `test/goldens/live_components_golden_test.dart`
  on the same pinned toolchain), not new renders.
  - These components are **not** used by any production screen.
  - They appear only in the debug gallery.

## Observations (facts only)

### Global / navigation

- Every screen has a near-black background (`#0B0B0D`). Accent red is used for the primary
  button, links, the selected nav item and the logo word "Live".
- The bottom nav appears on Home, Discover, Create, Live and Profile.
  - It has 5 equal slots with an icon and a label: Home, Discover, Create, Live, Profile.
  - The centre slot is a red rounded-rectangle pill containing a white "+", with no label under
    it.
  - Selected: a filled icon and the label in red. Unselected: outline icons and grey labels.
  - The nav bar has a slightly lighter surface and a 1 dp top divider.
- In Arabic the whole layout mirrors: the nav order runs Home on the right to Profile on the
  left, and titles are right-aligned.
- No tab has a top tab bar, search field, category chips, banner or any content list. Below
  the title, every tab shows only a single centred empty state.
- No screen shows a status bar (headless render; see above).

### Auth

- **Splash:** the "Kabso Live" wordmark is centred (white "Kabso", red "Live"), with a small
  red circular spinner below it, on a plain black background. It looks the same in ar and en.
- **Login:**
  - A language toggle sits at the top end, an outlined pill with a globe icon showing the
    *other* language ("العربية" in en, "English" in ar).
  - The content block is vertically centred and start-aligned: wordmark, headline "Log in",
    subtitle, two outlined text fields (email or username; password with an eye toggle).
  - Then a red "Forgot password?" text link at the end, a full-width red pill "Log in" button,
    and a centred "Don't have an account? Create account" line.
  - There is no illustration, social login, or third-party sign-in.
- **Register:** the same scaffold as Login.
  - Four fields: email, username (with a helper line about allowed characters), display name
    (with a helper and a "0/50" counter) and password (with an "At least 8 characters" helper).
  - Then a full-width red "Create account" button, two caption lines (the code notice and the
    terms notice) and a "Log in" link.
  - The form fills most of the screen height.
- **Code entry:**
  - A back arrow sits at the top start; it mirrors to point right in ar.
  - Then the wordmark, "Check your email" and a body text that includes the email address.
  - A red "Change email" link sits above 8 separate code cells in two groups of 4. The first
    cell has a red focus outline.
  - The cells read left to right in both locales.
  - Below them come an expiry hint, a disabled dark-red "Verify" button, an outlined disabled
    "Send a new code in 1:00" button and an "Already have an account? Log in" line.

### Shell tabs (all signed in)

- **Home:**
  - The top bar has only the "Kabso Live" wordmark at the start, with no actions.
  - The centre shows a circular grey badge with a red "stacked cards" icon, the headline "Your
    feed is on its way" and a two-line body naming Phase 2 and Phase 3.
  - The rest of the screen is empty.
- **Home (light):** the same layout on white, with a darker red accent and a light-grey nav
  surface.
- **Discover:** the title "Discover" at the top start, then the same centred empty-state
  pattern (compass icon, "Discover is coming", Phase 2/9 text).
- **Create:** the title "Create", then the same pattern (image-plus icon, "Creating is coming",
  a three-line Phase 3–6 text).
  - Tapping the Create tab opens this regular page; it does not open a sheet or a camera.
- **Live:**
  - The title "Live", then the same pattern (TV icon, "Live rooms are coming", Phase 6/7 text).
  - No live cards, categories or "Go live" entry point are shown.
- **Profile:**
  - The top bar shows `@layla.k` at the start and a settings gear at the end.
  - Then a large grey circular avatar with the initial "L", the display name "Layla" and
    `@layla.k` in grey.
  - Below them, an outlined card shows a grid icon, "Your posts will live here" and Phase 2–4
    text.
  - There are no counts (followers, following, likes), no edit button and no tabs.

### Settings

- The title "Settings", then four sections with small grey headers:
  - **Appearance:** a 3-way segmented control (Match device, Dark, Light); the selected
    segment is filled red. In ar, "Match device" wraps onto three lines.
  - **Language:** a 2-way segmented control (العربية, English).
  - **Active sessions:** a phone icon, the device name, platform, version, last active and the
    sign-in date. The other session has a red "End" text button.
  - **Account:** a red "Log out" row.
- A "Component gallery" row appears at the bottom (debug builds only).

### Debug component gallery (not reachable in release)

- An app bar titled "Component gallery". Section titles are English in both locales, by
  design (developer-facing).
- The sections, in order:
  - **Badges:** red "LIVE" / "مباشر" and a red-gradient "PK" badge, plus dark viewer pills
    with an eye icon and compact counts ("12.3K" / "12.3 ألف", "1.2M" / "1.2 مليون").
  - **Avatar rings:** grey initial avatars with no ring, a red ring, a grey ring and a red
    gradient ring with a "LIVE" tab.
  - **Scrollable tabs:** "All" selected with a red underline.
  - **Live cover cards:** shown without cover images, so they display "Cover couldn't load".
    A skeleton card follows.
  - **PK score bar:** two bars (9,000 vs 1,000 with "1:35 left", and 4,200 vs 3,800 with a
    gold "Win" chip). The host's pink side is on the right in ar.
  - **Chat overlay:** over a grey placeholder whose camera icon shows through behind the chat

  - **Buttons:** "Gifts" (red) and "Live" (outlined), which open the demos.
- In ar the gift chat line with an English gift name renders as "3× Star Viewer B أرسل": the
